# ViewShop
<p>ViewShop is a backend application built with NestJS, providing the core functionality of an online marketplace. It handles business logic, manages application data, and exposes structured APIs to support communication between clients and the server.</p>

  <h2><img width="30" height="30" alt="image" src="https://github.com/user-attachments/assets/a1b95a4b-28ad-4e73-b485-165bb2951e2d" /> Setup & Installation</h2>
  <div>
    <h3>1: clone repo</h3>
    
```     
 git clone https://github.com/AminAhmadi070807/viewshop.git
```

  <h3>2: entering the project</h3>
    
```
cd ./viewshop/SERVER/gateway
cd ./viewshop/SERVER/guard
cd ./viewshop/SERVER/core
```

  <h3>3: installation package project</h3>
    
```
npm i
```

  <h3>4: start the server</h3>
    
```
npm run start
```

  <h3>5: entering this address to broswer</h3>
    
```
http://localhost:3000/api/v1/core/docs
http://localhost:3000/api/v1/guard/docs
```
